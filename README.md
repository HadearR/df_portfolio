## projects

[MBTA Project](https://HadearR.github.io/df_portfolio/Projects/MBTA.html)

An Analysis of MBTA rapid transit reliability using On Time Performance data.

- Cleaned, filtered, and analyzed a large MBTA dataset to focus on rapid transit service.
- Explored how factors such as **transit line, year, and peak/off-peak** service relate to reliability.
- Created visualizations to compare On Time Performance across MBTA lines and over time.
- Used **linear regression and regression tree models** to examine and predict differences in On Time Performance.
- Compared model performance to determine which approach better explained variation in MBTA reliability.
- **Keywords**( R, Tidyverse, Data Cleaning, Data Wrangling, Data Visualization, Linear Regression, Regression Trees, MBTA)

[Ready, Set, Go: A Data Wrangling Tutorial Using Vehicles Dataset](https://HadearR.github.io/df_portfolio/Projects/Project3.html)

A step-by-step tutorial demonstrating data wrangling techniques in R using EPA fuel economy data.

- Used R to clean and organize vehicle fuel economy data.
- Explored the data to identify patterns in vehicle classes and fuel efficiency.
- Created visualizations comparing fuel efficiency across vehicles with different numbers of cylinders.
- Demonstrated common data wrangling and visualization techniques throughout the tutorial.
-**Keywords** (R, Tidyverse, Data Wrangling, Data Cleaning, Data Visualization, EPA Fuel Economy)
